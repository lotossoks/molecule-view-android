# Проверка Palmol 0.1.0

Дата: 1 ноября 2026 года.

## Сборка

- Kotlin/Compose debug и release APK собираются.
- Android Lint: ошибок нет; есть предупреждения о версиях зависимостей, target SDK и использовании JavaScript в локальном WebView.
- Release подписан постоянным ключом Palmol; проверка `apksigner verify` выполняется в CI.
- APK включает ARM64, ARMv7, x86 и x86_64. ARM64-библиотека AndroidX Graphics имеет ELF alignment 0x4000.

## Автоматические проверки движка

`web/tests/smoke.mjs` проходит в Chromium со SwiftShader. Перед запуском удаляется `Object.hasOwn` для проверки начальной совместимости со старым WebView. Отдельно выполнен тот же набор с `PALMOL_LEGACY=1`, который включает совместимый WebGL1-режим.

- PDB с двумя моделями: загрузка, переход между состояниями.
- Выделение касанием, выражение по остаткам, именованные выборки и `byres (site around 5)`.
- Окружение выбранного фрагмента, стили и цвета.
- Расстояние между двумя атомами.
- Экспорт PNG.
- Сохранение сессии, загрузка другой структуры, восстановление исходной сессии и последующее редактирование стилей/окружения.
- MOL2, GRO, SDF и XYZ: синтетические структуры с проверкой числа атомов.
- mmCIF и BinaryCIF RCSB 1CRN: оба дают 327 атомов; отдельная проверка BinaryCIF-сессии.
- При `PALMOL_STRESS=1` проходит загрузка и выборка 100 000 синтетических атомов XYZ. Это не измерение FPS на телефоне.

## Android

Подписанный release APK успешно проверен на Android 12 / API 31 (WebView 91), эмулятор Pixel 2 x86_64 с графическим backend SwANGLE. [Успешный запуск](https://github.com/lotossoks/molecule-view-android/actions/runs/41315111339).

Сценарий устанавливает APK, ждёт готовности viewer, открывает встроенный PDB, переключает состояния вперёд/назад, открывает/закрывает панель выделения и проверяет цветные пиксели молекулы на снимке экрана. PID Palmol сохраняется, исключений FATAL EXCEPTION в его процессе нет. Снимки и журнал доступны в артефакте `Palmol-android-smoke`.

Проверен APK из [сборки](https://github.com/lotossoks/molecule-view-android/actions/runs/41313535930), commit `bd20f82`. Сборка, web-тесты, lint и проверка подписи завершились успешно; её первоначальный эмуляторный этап был остановлен после отключения эмулятора. Независимый успешный запуск выше использовал тот же APK без пересборки. Предыдущий графический backend эмулятора SwiftShader indirect давал артефакты изображения/отключение устройства; CI переведён на SwANGLE. На WebView ниже Chrome 100 приложение выбирает совместимый WebGL1-режим.

SHA-256 APK: `a0b15f71f476dd0742eedb49c7e222f75789ae184de7adf189072f94939b9276`.
