# Palmol — молекула в ладони

Android-приложение для просмотра молекулярных структур. Kotlin/Jetpack Compose и локальный Mol*: файлы отображаются на устройстве, без загрузки на сервер.

## Установка

Android **12+**. Устанавливаемый подписанный APK публикуется в GitHub Releases этого приватного репозитория; нужен вход в GitHub с доступом к нему. Для установки разрешите браузеру/файловому менеджеру устанавливать приложения. Рекомендуется актуальный Android System WebView.

## Возможности v0.1

- Локальные PDB/ENT, mmCIF/CIF, BCIF, MOL2, GRO, SDF/MOL, XYZ; формат определяется расширением.
- Загрузка mmCIF по PDB-коду и офлайн-список недавних файлов.
- Multi-state PDB: предыдущая/следующая модель и счётчик. Подходит для ЯМР и MD, записанной блоками MODEL; физическое время не выводится из номера модели.
- Cartoon, sticks, ball-and-stick, spheres, surface, lines; стили всей структуры или выделения, цвета по элементам/цепям и именованные цвета из консоли.
- Выделение касанием на уровне атома/остатка/цепи либо выражением PyMOL. Окружение в Å с расширением до целых остатков, фокус и изоляция.
- Консоль, именованные выборки, история, экспорт истории в текстовый сценарий.
- Расстояние между двумя атомами через команду `distance`.
- Сохранение самодостаточной сессии `.palmol`, повторное открытие офлайн и экспорт PNG через системный диалог.
- Встроенный маленький двухмодельный PDB для проверки установки без сети: **Open → Demo: two states**.

## Управление

Один палец вращает, два переносят, pinch масштабирует. Касание выделяет остаток; уровень меняется в Select. Панели Open / Style / Select / Console закрываются кнопкой Close или Android Back. Смена ориентации сохраняет текущую сцену. Для сохранения между запусками используйте More → Save session.

В Style сначала укажите, применяется ли стиль только к выделенным атомам. Окружение включает исходный фрагмент; по умолчанию расширяется до целых остатков. Команда `around` следует семантике транслятора PyMOL и исключает исходную выборку.

```text
fetch 1crn
select site, chain A and resi 10-25
select pocket, byres (site around 5)
show sticks, pocket
color yellow, pocket
zoom pocket
distance d1, id 1, id 2
frame 2
```

`fetch` выполняется Android-слоем. `select`, `show`, `hide`, `color`, `zoom`/`focus`, `reset`, `distance`, `frame` — поддерживаемое подмножество команд. `sele` означает текущее выделение. `hide everything, all` удаляет все отображаемые слои; `hide everything, pocket` — именованный слой. Произвольные подвыборки в `hide` пока не поддерживаются: для них используйте Isolate. `distance` требует ровно один атом в каждой конечной выборке. Это не полный PyMOL/Python runtime: неподдержанные команды показывают ошибку.

## Ограничения первой версии

Одна загруженная структура за раз; локальный файл до 128 MB. Данные структуры и сессии разбираются в памяти, поэтому большой файл может потребовать значительно больше RAM. 100 тысяч атомов — целевой масштаб, а не подтверждённый предел на всех телефонах. Поверхности особенно требовательны к памяти.

GRO содержит координаты, но не полную силовую топологию; часть связей может определяться движком. Кристаллографические сборки и symmetry mates отдельно не выбираются. Выделения при смене модели очищаются; именованные выражения и стили пересчитываются движком. Для ансамблей с разным составом проверяйте результат вручную. Формат `.palmol` v1 закреплён на Mol* 4.18.0; перенос между будущими несовместимыми версиями потребует миграции.

XTC/TRR, произвольные большие MD-траектории, SFTP и ProxyJump относятся к следующему релизу, как согласовано в архитектуре. [План и исследование](docs/architecture.md).

## Сборка и проверки

Node 22, JDK 17, Android SDK 35, Gradle 8.11.1:

```sh
cd web
npm ci
npm run build
cd ..
gradle assembleDebug
```

Release подписывается постоянным ключом из GitHub Actions Secrets. Локальные ключи лежат в игнорируемой `.keys/`; не удаляйте их без резервной копии, иначе обновление установленного APK тем же сертификатом станет невозможным. Не публикуйте ключи или пароли.

Web smoke test: запустить `python3 -m http.server 8765 --bind 127.0.0.1` из корня, затем `node web/tests/smoke.mjs`. Тест использует Chrome из `/opt/google/chrome/chrome` и проверяет модели, выборки/окружение, стили, расстояние, roundtrip сессии, PNG, MOL2/GRO/SDF/XYZ. CI собирает APK и запускает Android smoke test на API 31. Проверка реального Honor под Android 16 остаётся пользовательским тестированием.
